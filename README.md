# Segmentation Profile Analyzer

Локальное приложение на Python 3.11+ и PySide6 для воспроизводимого описательного анализа сегментации письменной речи в интернет-переписке. Оно загружает TXT, рассчитывает профиль выбранного участника, сравнивает профили, проверяет чувствительность к временному порогу и экспортирует таблицы в CSV/XLSX. Интернет во время анализа не используется.

> Получаемые показатели являются описательными характеристиками письменной речи в интернет-переписке. Программа не устанавливает авторство текста и не рассчитывает вероятность принадлежности текста конкретному лицу.

Программа не применяет машинное обучение, не рассчитывает общий показатель сходства и не классифицирует признаки как устойчивые или идентификационные. Интерпретацию выполняет исследователь.

## Установка и запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\launch.cmd
```

На Linux/macOS используйте `python3 -m venv .venv`, `.venv/bin/python -m pip install -r requirements.txt` и `.venv/bin/python main.py`.

## Формат переписки

```text
[11.06.2026 9:12] Автор А: привет
[11.06.2026 9:13] Автор Б: уже иду
[11.06.2026 9:14] Автор А в ответ Автор Б:
> уже иду
хорошо))
```

Поддерживаются UTF-8 с BOM или без него и Windows-1251, одно- и двузначные часы, необязательные секунды, а также конструкции `в ответ` и `in reply to`. Цитаты после `>` сохраняются отдельно и не входят в собственный текст. Медиамаркеры (`[Голосовое сообщение]`, `[Video message]`, `[Стикер]`, `[Фотография]`, `[Photo]`, `[Видео]` и варианты с пробелами внутри скобок) исключаются. Отдельная текстовая подпись к медиа сохраняется.

## Серии сообщений

Серия сообщений — последовательность сообщений одного автора, не прерываемая сообщением другого участника и не разделённая временным интервалом, превышающим установленный порог. Порог выбирается в интерфейсе: 5, 10 или 30 минут; значение по умолчанию — 10 минут.

Сегментация выполняется по полной переписке до выбора целевого автора. Поэтому даже исключённое медиасообщение собеседника завершает серию. Порядок строк файла сохраняется. В таблице сообщений доступны номер серии, позиция, длина серии и разрыв с предыдущим сообщением того же автора в секундах.

## Показатели

Параметры сегментации:

| Поле | Определение |
|---|---|
| `message_count` | Количество текстовых сообщений |
| `median_words_per_message` | Медиана числа слов |
| `mean_words_per_message` | Среднее число слов |
| `q1_words_per_message` | 25-й процентиль числа слов |
| `q3_words_per_message` | 75-й процентиль числа слов |
| `iqr_words_per_message` | Q3 − Q1 |
| `one_word_ratio` | Доля сообщений ровно из одного слова |
| `short_message_ratio` | Доля сообщений длиной не более трёх слов |
| `series_count` | Количество серий |
| `median_series_length` | Медианное количество сообщений в серии |
| `mean_messages_per_series` | Среднее количество сообщений в серии |
| `single_message_series_ratio` | Доля серий ровно из одного сообщения |
| `long_series_ratio` | Доля серий длиной не менее трёх сообщений |

Параметры оформления границ сообщений:

| Поле | Определение |
|---|---|
| `no_standard_final_punctuation_ratio` | Доля сообщений, не заканчивающихся `.`, `!`, `?` или `…` |
| `lowercase_start_ratio` | Доля сообщений, где первый буквенный символ строчный; сообщения без букв исключаются из знаменателя |
| `bracket_ending_ratio` | Доля сообщений, заканчивающихся одной или несколькими `)` |

Слово — последовательность Unicode-букв или цифр с возможными внутренними дефисами и апострофами. `когда-нибудь` и `18-20` считаются одним словом. URL считается одним токеном. Emoji и отдельная пунктуация словами не считаются.

## Режимы исследования

Обычный профиль показывает показатели, таблицы `Messages` и `Series`, распределения длины сообщений и серий. Таблица `Series` содержит начало, конец, количество сообщений, число слов, среднюю длину сообщения, длительность и использованный порог.

«Внутриавторское сравнение» принимает два или три профиля и показывает значения, минимум, максимум и размах. В XLSX также записывается агрегированный описательный профиль со средним, медианой, минимумом, максимумом и размахом по реализациям речи.

«Межавторское сравнение» показывает два профиля и абсолютную разницу по каждому параметру. Для долей числовая разница соответствует процентным пунктам при отображении в процентах. Общий рейтинг сходства не строится.

«Проверка порога серии» автоматически пересчитывает пять параметров серий при порогах 5, 10 и 30 минут. Вкладка «Корпус» позволяет добавить несколько файлов и редактировать поля `corpus_id`, `author`, `interlocutor`, `source_file`, `message_count`, `date_start`, `date_end` и `notes`.

Расчётная функция `variability_comparison` в `profiles.py` сопоставляет размахи минимум двух профилей автора A, минимум двух профилей автора B и разницу между средними без автоматического вывода о значимости.

## Экспорт

Обычный XLSX содержит `Profile`, `Messages`, `Series`. Межавторский — `Author_A`, `Author_B`, `Between_Author_Comparison`. Внутриавторский — `Profile_1`, `Profile_2`, при наличии `Profile_3`, `Within_Author_Comparison`, `Aggregated_Profile`. Анализ порогов содержит `Threshold_5`, `Threshold_10`, `Threshold_30`, `Threshold_Comparison`.

Строки, начинающиеся с `=`, записываются в Excel как текст. Ячейки длиннее лимита Excel вызывают явную ошибку. Доли хранятся числами от 0 до 1 без округления.

## Ограничения

Результаты зависят от размера и полноты выборки, темы, собеседника, способа экспорта и выбранного временного порога. Программа не восстанавливает отсутствующую разметку участников. Системные события и неизвестные форматы экспорта могут потребовать адаптации парсера. Квартильные оценки на малых выборках нестабильны. Анализ выполняется в потоке интерфейса, поэтому очень большой файл может временно задержать его работу.

Архитектура: `parser.py` → `segmentation.py` → `features.py` → `profiles.py` → `comparison.py` → `export.py` → `ui/`. Расчёты отделены от интерфейса.
