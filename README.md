# Анализатор сегментации переписки

Локальное desktop-приложение на Python 3.11+ и PySide6: загрузка TXT, выбор автора, 13 параметров сегментации, таблица сообщений, три графика, сравнение двух профилей, экспорт CSV/XLSX. Интерфейс на русском. Во время работы интернет не используется.

Приложение не осуществляет автоматическую идентификацию автора. Получаемые показатели предназначены для исследовательского и экспертно-аналитического использования и требуют интерпретации специалистом.

## Установка

Установите Python 3.11 или новее. В PowerShell проверьте `python --version` (или `py -3 --version`, если установлен Python Launcher). В папке проекта выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Если доступна только команда `py`, первая команда: `py -3 -m venv .venv`. Если обе команды отсутствуют, сначала установите Python и откройте новый PowerShell. После установки зависимостей в Windows используйте `launch.cmd`. Он запускает `.venv` из папки проекта. Интернет нужен только при установке зависимостей.

На Linux/macOS: `python3 -m venv .venv`, затем `.venv/bin/python -m pip install -r requirements.txt` и `.venv/bin/python main.py`.

## Использование и формат TXT

```text
[11.06.2026 9:12] Автор А: привет
[11.06.2026 9:12] Автор А: ты где
[11.06.2026 9:13] Автор Б: уже иду
[11.06.2026 9:14] Автор А в ответ Автор Б:
> уже иду
хорошо))
```

Загрузите TXT, выберите автора и нажмите «Анализировать». Вкладки показывают профиль, сообщения и графики. Сортировка таблицы не меняет порядок расчёта серий. В сравнении загрузите два независимых файла и выберите автора в каждом. Например, `chat_a.txt` и `chat_b.txt`, автор «Автор А». Показываются значения и абсолютная разница, без общего процента совпадения.

Поддерживаются UTF-8 с/без BOM и Windows-1251, одно- и двузначные часы, необязательные секунды. Многострочные сообщения объединяются; строки `>` сохраняются отдельно как цитаты и не входят в собственный текст. Регистр, emoji, ссылки, опечатки и пунктуация сохраняются.

Пустые сообщения и чистые цитаты исключаются. Точные маркеры вложений перечислены в `parser.py`: например `[стикер]`, `[изображение]`, `[голосовое сообщение]`, `<Media omitted>`. Подпись на отдельной строке сохраняется. Строки с датой без `Автор:` считаются системными событиями. Неизвестные служебные маркеры внутри сообщений требуют адаптации парсера; обычные слова «фото» и «стикер» не удаляются.

Серия — последовательность сообщений одного автора, не прерванная другим участником. Она определяется по полной переписке до выбора автора. Исключённое сообщение другого участника прерывает серию, но не увеличивает число текстовых сообщений. Системное событие без автора не прерывает серию. Временной промежуток не прерывает серию. Сохраняется порядок файла, без сортировки по дате.

## Операционализация признаков, версия 1


Слово — последовательность Unicode-букв/цифр, с возможными внутренними дефисами и апострофами. Число считается словом. `кто-то` и `don't` — по одному слову; подчёркивание разделяет слова. Ссылка с `http://`, `https://` или `www.` считается одним словом. Отдельные emoji и знаки пунктуации словами не считаются. Поэтому сообщение из emoji содержит 0 слов и относится к коротким, но не к однословным.

Обозначения: N — число текстовых сообщений автора, S — число его серий, w — число слов в сообщении, l — длина серии. Пустой выбор автора вызывает ошибку, а не нулевой профиль.

| Поле | Правило |
|---|---|
| `message_count` | N |
| `median_words_per_message` | Медиана всех w |
| `mean_words_per_message` | Среднее всех w |
| `one_word_ratio` | Число сообщений с w=1 / N |
| `short_message_ratio` | Число сообщений с w≤3 / N, включая w=0 |
| `median_series_length` | Медиана l, каждая серия учитывается один раз |
| `mean_series_length` | Среднее l, каждая серия учитывается один раз |
| `long_series_ratio` | Число серий с l≥3 / S |
| `no_standard_final_punctuation_ratio` | Доля сообщений, чей последний непробельный символ не `.`, `!`, `?`, `…` |
| `bracket_ending_ratio` | Доля сообщений, оканчивающихся одной или несколькими `)` после удаления конечных пробелов |
| `lowercase_start_ratio` | Доля сообщений, у которых первая буквенная буква строчная; перед поиском убираются URL, пропускаются числа, emoji и прочие небуквенные знаки |
| `multi_sentence_ratio` | Доля сообщений с минимум двумя группами подряд идущих `[.!?…]+`; URL предварительно исключаются |
| `mean_words_in_multi_message_series` | Среднее w по сообщениям, входящим в серии l≥2; если таких нет, значение отсутствует (`—` / пустая ячейка) |

`?!`, `!!!`, `...` считаются **одной** приблизительной границей предложения, чтобы экспрессивная пунктуация не создавала ложные несколько предложений сама по себе. Сокращения (`p.m.`, `т.д.`), десятичные числа и иные внутренние точки могут завышать оценку. Фраза с единственным конечным знаком и незавершённым вторым предложением может недооцениваться. Это явная эвристика, а не лингвистический синтаксический анализ.

Проверка конечной пунктуации буквальная: `да!😀`, `«да!»` и `да))` не оканчиваются стандартным знаком. Для текста без букв `lowercase_start` равен false; такой текст остаётся в знаменателе N. Эти решения одинаковы для всех корпусов. Доли в экспорте хранятся от 0 до 1 без округления; UI профиля показывает проценты.


## Экспорт и тесты

CSV содержит `source_file`, `author` и 13 параметров; кодировка UTF-8 с BOM. XLSX содержит `Profile`, `Messages`, `Series`, а при сравнении — `Profile_A`, `Profile_B`, `Comparison`. Технические имена экспортных полей сохранены на английском. Цитаты находятся в `quoted_text`. Значения, начинающиеся с `=`, сохраняются в Excel как текст. Слишком длинный для Excel текст вызывает ошибку вместо усечения.

Объект `Analysis` содержит распределения `message_word_lengths` и `series_lengths`; их можно также получить из таблиц сообщений и серий. Доли экспортируются от 0 до 1. Отсутствующее среднее по сериям ≥2 показывается как «—» и пустая ячейка.

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe main.py --file chat_a.txt --author "Автор А" --output profile.xlsx
```

После активации окружения тесты также запускаются командой `pytest`. Тестовые примеры синтетические; реальные переписки и результаты их анализа в репозиторий не включены.

## Ограничения

Параметры зависят от размера выборки, собеседника, темы и полноты экспорта. Если все заголовки приписаны одному автору, получится одна серия; программа предупреждает об этом, но не восстанавливает авторство. Приблизительные границы предложений могут ошибаться на сокращениях и числах. Имена авторов не должны содержать двоеточие или разделитель ` в ответ `.

Приложение предназначено для небольших исследовательских корпусов. Анализ выполняется в потоке GUI; очень большой файл может временно задерживать интерфейс. Автоматическая идентификация автора, ML, API мессенджеров и суммарная оценка сходства отсутствуют.

## Структура

`parser.py` → `segmentation.py` → `features.py` → `comparison.py` → `ui/` и `export.py`. Расчёты отделены от GUI. `tests/` проверяет парсинг, цитаты, серии, признаки, экспорт и интерфейс.
